دهکده نمدی سارا — نسخه بازطراحی‌شده مطابق نمونه GeminAi.html
======================================================

فایل‌ها
- index.html: سایت عمومی با تم صورتی/رزگلد، فونت وزیرمتن، بخش معرفی، جست‌وجو، فیلتر دسته‌بندی، کارت محصول و پنجره جزئیات؛ محصولات منتشرشده را از Supabase می‌خواند.
- admin.html: پنل مدیریت با همان هویت بصری، ورود مدیر، آمار محصولات، فرم افزودن/ویرایش و فهرست قابل جست‌وجو؛ حذف، انتشار و مخفی‌کردن.
- supabase-config.js: محل تنظیم Project URL و anon/publishable key.
- supabase-schema.sql: ساخت جدول، دسترسی‌ها و فضای فایل‌ها در Supabase.
- 404.html: صفحه خطا.

مهم
این نسخه بعد از وارد کردن تنظیمات Supabase و اجرای SQL کار می‌کند. هنوز به پروژه Supabase شما متصل نیست چون پروژه و کلیدهای آن باید در حساب خودتان ساخته شوند.
هرگز service_role key یا کلید محرمانه را در فایل‌های سمت مرورگر قرار ندهید.

بخش اول — ساخت فضای ذخیره‌سازی
1. به https://supabase.com بروید و یک حساب بسازید.
2. یک پروژه جدید بسازید (نام مثلاً dehkade-namadi-sara). رمز پایگاه داده را در جای امن نگه دارید.
3. از داشبورد پروژه به SQL Editor بروید.
4. فایل supabase-schema.sql را باز کنید، تمام متنش را کپی کنید و در SQL Editor اجرا کنید.
5. به Project Settings > API یا بخش Connect بروید و Project URL و کلید عمومی anon/publishable را بردارید.
6. فایل supabase-config.js را باز کنید و مقادیر نمونه را با URL و کلید عمومی پروژه خود جایگزین کنید.
   - SUPABASE_URL = آدرس پروژه
   - SUPABASE_ANON_KEY = کلید عمومی anon/publishable
   - کلید service_role/secret را هرگز وارد نکنید.

بخش دوم — ایجاد حساب مدیر
1. در Supabase به Authentication > Users بروید.
2. Add user / Create new user را انتخاب کنید و ایمیل و رمز قوی مخصوص مدیر بسازید.
3. ثبت‌نام عمومی برای کاربران را لازم ندارید؛ حساب مدیر را فقط خودتان بسازید.
4. پنل admin.html از همان حساب واردشده استفاده می‌کند. در این نسخه سیاست جدول اجازه مدیریت به کاربران authenticated می‌دهد؛ بنابراین پروژه را فقط برای مدیر نگه دارید و حساب کاربری عمومی نسازید. برای محیط حساس/چندمدیره بهتر است سیاست‌ها به جدول مجزای adminها محدود شود.

بخش سوم — انتشار روی Netlify
1. همه فایل‌های همین پوشه را در یک پوشه محلی نگه دارید.
2. فایل ZIP را پس از تکمیل supabase-config.js دوباره بسازید یا خود پوشه را در Netlify Drop بارگذاری کنید: https://app.netlify.com/drop
3. مطمئن شوید index.html، admin.html، supabase-config.js، 404.html و robots.txt در ریشه سایت قرار دارند.
4. پس از انتشار، صفحه عمومی با آدرس اصلی سایت و پنل مدیریت در آدرس /admin.html در دسترس خواهد بود.
5. قبل از استفاده واقعی، ورود پنل، افزودن یک محصول آزمایشی، انتشار، نمایش در سایت و سفارش واتساپ را آزمایش کنید.

کار با پنل
- باز کنید: https://آدرس-سایت-شما/admin.html
- با ایمیل و رمز مدیر وارد شوید.
- عنوان، دسته‌بندی، توضیحات، قیمت اختیاری و عکس/ویدئو را وارد کنید.
- با تیک «انتشار در سایت» محصول را منتشر کنید؛ در غیر این صورت فقط در پنل می‌ماند.
- برای تغییر اطلاعات از «ویرایش»، برای مخفی‌کردن «مخفی‌کردن» و برای حذف «حذف» را انتخاب کنید.
- تصاویر در Storage و اطلاعات محصول در جدول products ذخیره می‌شوند.

نکات و محدودیت‌ها
- هر فایل رسانه‌ای در این قالب تا 50MB مجاز است؛ محدودیت‌ها و قیمت‌های سرویس Supabase ممکن است تغییر کنند.
- حذف محصول در این نسخه رکورد را حذف می‌کند، اما فایل‌های ذخیره‌شده قدیمی را خودکار پاک نمی‌کند.
- پنل فعلاً امکان افزودن چند فایل و نمایش اولین فایل به‌عنوان تصویر اصلی را دارد؛ گالری چندتصویری پیشرفته و مرتب‌سازی دستی قابل توسعه است.
- تصاویر و پست‌های نمونه در سایت عمومی باقی می‌مانند تا زمانی که حداقل یک محصول واقعی منتشر کنید؛ پس از آن گالری از محصولات پایگاه داده استفاده می‌کند.
- برای امنیت، رمز مدیر را با کسی به اشتراک نگذارید و کلید service_role را در فایل‌های سایت قرار ندهید.


بازطراحی ظاهری: این نسخه با الهام از فایل مرجع GeminAi.html بازطراحی شده است؛ شامل رنگ‌های صورتی و رزگلد، زمینه کرم/صورتی روشن، فونت Vazirmatn، آیکون‌ها، کارت‌های گرد، سایه ملایم، جست‌وجو و فیلتر دسته‌بندی. منطق اتصال به Supabase و جدول products حفظ شده است.
